# Lineups — запуск Telegram Mini App

Раскидки гранат для тактического шутера: карта с точками, анимированный проигрыватель броска (где встать, куда целиться, как бросить), лента, сохранённое, создание раскидок. Один HTML-клиент + zero-dep Node-бэкенд.

## Файлы

| Файл | Роль |
|------|------|
| `lineups.html` | Клиент Mini App. Работает и standalone (localStorage), и с бэкендом. |
| `lineups-server.js` | Бэкенд: initData-auth, синхронизация сейвов/просмотров, community-раскидки, deep-link. Отдаёт `lineups.html`. |
| `lineups-setup.js` | Разовая настройка бота через Bot API (кнопка меню → Web App). |
| `package.json` | start/setup-скрипты, node ≥18. |
| `render.yaml` | Blueprint для деплоя на Render. |
| `.gitignore` | Исключает `lineups-data.json`, `node_modules`, `.env`. |

## Быстрый старт локально

```bash
node lineups-server.js          # DEV: без BOT_TOKEN, initData не проверяется
# открыть http://localhost:8080
```

## Запуск в бой (5 шагов)

**1. Бот в @BotFather**
- `/newbot` → получи `BOT_TOKEN` и `username` бота.
- (для deep-link ссылок) `/newapp` → задай короткое имя приложения = твой `APP_NAME`.

**2. Репозиторий**
Этот репозиторий уже готов к деплою (все файлы названы правильно) — просто подключи его к Render.

**3. Деплой (Render, план free)**
- New → Blueprint → подключи репозиторий (Render прочитает `render.yaml`).
- Задай переменные окружения:
  - `BOT_TOKEN` — токен из BotFather (включает строгую проверку initData)
  - `BOT_USERNAME` — username бота без `@`
  - `APP_NAME` — short name из `/newapp` (для ссылок «поделиться»)
  - `AUTO_APPROVE` — `1` (публиковать сразу) или `0` (модерация)
- Получишь публичный `https://<name>.onrender.com`. Проверь `GET /health`.

**4. Привязать Web App к боту**
```bash
BOT_TOKEN=123:ABC PUBLIC_URL=https://<name>.onrender.com node lineups-setup.js
```
Скрипт ставит кнопку меню бота на Web App и описание. После — открой чат с ботом и жми «Раскидки».
Для именованного Mini App (`t.me/<bot>/<app>`) в BotFather у Mini App укажи URL = тот же `PUBLIC_URL`.

**5. Проверка**
- Открытие из чата бота (кнопка меню) и из `t.me/<bot>/<app>`.
- Сохранение раскидки → перезапуск → сейв на месте (синхронизация с сервером).
- «Поделиться» раскидкой → ссылка `?startapp=<id>` открывает нужную раскидку.

## Переменные окружения сервера

| Переменная | По умолчанию | Назначение |
|-----------|--------------|-----------|
| `PORT` | `8080` | Порт (Render задаёт сам). |
| `BOT_TOKEN` | — | Токен бота. Если задан — initData проверяется строго; иначе DEV. |
| `BOT_USERNAME` | — | Для ссылок «поделиться». |
| `APP_NAME` | — | Short name Mini App для deep-link. |
| `AUTO_APPROVE` | `1` | `1` — submit публикуется сразу; `0` — pending/модерация. |
| `PUBLIC_URL` | — | Только для логов/справки. |

## Архитектура и границы MVP

- **Каталог**: базовые 24 раскидки зашиты в `lineups.html` (офлайн-фолбэк). Сервер хранит только пользовательское состояние (`users`) и community-раскидки (`subs`) в `lineups-data.json`. Клиент накатывает серверные данные поверх встроенного каталога; без сервера падает на localStorage.
- **Данные на Render free эфемерны**: `lineups-data.json` сбрасывается при передеплое/засыпании. Для прод — Render Disk (платно) или внешняя БД (Postgres/Redis) вместо JSON-файла.
- **Карты и «видео»** — синтетические: SVG-радары + анимированная траектория броска (реальные видео и картинки радаров не входят в MVP).
- **Оплаты/подписки** нет (в дизайне Premium помечен «СКОРО»). При необходимости — паттерн Telegram Stars как в `casino-manager-bot.js`.
